# Request PnL settlement

`POST /v1/settle_pnl`

**Authentication:** Wallet

**Rate limit:** 1 requests per 1 second

## Description

`verifyingContract` should use: `0x6F7a338F2aA472838dEFD3283eB360d4Dff5D203`.

## Parameters

| Name | Location | Type | Required | Description |
|---|---|---|---|---|
| `signature` | body | string | Yes | The signature generated by signing the message object via EIP-712 |
| `userAddress` | body | string | Yes | The address of the wallet signing the message object via EIP-712 |
| `verifyingContract` | body | string | Yes | Address of the RWA Perp ledger contract |
| `message` | body | object | Yes | Message object containing the message that is signed by the wallet owner |
| `message.brokerId` | body | string | Yes | Builder ID |
| `message.chainId` | body | integer | Yes | Chain ID of registering chain (within those that are supported by the Network) |
| `message.chainType` | body | string | No | Chain type of the signing wallet. Supported values are `EVM` and `SOL`. |
| `message.settleNonce` | body | integer | Yes | Nonce returned by Get Settle PnL Nonce. |
| `message.timestamp` | body | integer | Yes | current timestamp in UNIX milliseconds |

## Responses

### HTTP 200

OK

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | boolean | Yes | Indicates whether the request was successful. Example: `True` |
| `timestamp` | integer | No | Server timestamp in milliseconds. Example: `1702989203989` |
| `data` | object | Yes | — |
| `data.settle_pnl_id` | integer | Yes | Example: `1` |
