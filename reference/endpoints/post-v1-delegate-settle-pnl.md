# Delegate signer settle PnL

`POST /v1/delegate_settle_pnl`

**Authentication:** Wallet

**Rate limit:** 1 requests per second

## Description

Requests PnL settlement on behalf of an account using an authorized delegate signer.

## Parameters

| Name | Location | Type | Required | Description |
|---|---|---|---|---|
| `signature` | body | string | Yes | Signature generated by signing the message object. |
| `userAddress` | body | string | Yes | Address of the wallet that signed the message object. |
| `verifyingContract` | body | string | Yes | Contract address used to verify the wallet signature. |
| `message` | body | object | Yes | Message object signed by the wallet owner. |
| `message.delegateContract` | body | string | Yes | — |
| `message.brokerId` | body | string | Yes | Builder ID |
| `message.chainId` | body | integer | Yes | Chain ID associated with the settlement request. |
| `message.settleNonce` | body | integer | Yes | Nonce returned by Get Settle PnL Nonce. |
| `message.timestamp` | body | integer | Yes | current timestamp in UNIX milliseconds |

## Responses

### HTTP 200

OK

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | boolean | Yes | Indicates whether the request was successful. Example: `True` |
| `timestamp` | integer | No | Server timestamp in milliseconds. Example: `1702989203989` |
| `data` | object | Yes | — |
| `data.settle_pnl_id` | integer | Yes | Example: `1` |
