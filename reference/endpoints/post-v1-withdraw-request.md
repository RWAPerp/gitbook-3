# Create withdraw request

`POST /v1/withdraw_request`

**Authentication:** Wallet + RWA

**Rate limit:** 10 requests per 1 second per IP address

## Description

`verifyingContract` should use: `0x6F7a338F2aA472838dEFD3283eB360d4Dff5D203`.

If `allowCrossChainWithdraw` is `false` for a cross-chain withdrawal request, the request is rejected.

## Parameters

| Name | Location | Type | Required | Description |
|---|---|---|---|---|
| `signature` | body | string | Yes | The signature generated by signing the message object via EIP-712 |
| `userAddress` | body | string | Yes | The address of the wallet signing the message object via EIP-712 |
| `verifyingContract` | body | string | Yes | Contract address used to verify the wallet signature. |
| `message` | body | object | Yes | Message object signed by the wallet owner. |
| `message.brokerId` | body | string | Yes | Builder ID |
| `message.chainId` | body | integer | Yes | Chain ID associated with the withdrawal request. |
| `message.chainType` | body | string | No | Chain type of the signing wallet. Supported values are `EVM` and `SOL`. |
| `message.receiver` | body | string | Yes | Destination wallet address for the withdrawal. |
| `message.token` | body | string | Yes | The string representation of the token that is being withdrawn (eg "USDC") |
| `message.amount` | body | string | Yes | Amount of tokens to be withdrawn |
| `message.withdrawNonce` | body | string | Yes | Valid withdrawal nonce from Get withdrawal nonce |
| `message.timestamp` | body | string | Yes | current timestamp in UNIX milliseconds |
| `message.allowCrossChainWithdraw` | body | boolean | No | Whether to allow a cross-chain withdrawal. Defaults to `false`. |

## Responses

### HTTP 200

OK

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | boolean | Yes | Indicates whether the request was successful. Example: `True` |
| `timestamp` | integer | No | Server timestamp in milliseconds. Example: `1702989203989` |
| `data` | object | Yes | — |
| `data.withdraw_id` | integer | Yes | Example: `123` |
