# Delegate signer

`POST /v1/delegate_signer`

**Authentication:** Wallet

**Rate limit:** 1 requests per second

## Description

Registers a delegate signer relationship for an account using a wallet-signed message.

## Parameters

| Name | Location | Type | Required | Description |
|---|---|---|---|---|
| `message` | body | object | Yes | — |
| `message.delegateContract` | body | string | Yes | Example: `0xaddress` |
| `message.brokerId` | body | string | Yes | Builder ID Example: `woofi_pro` |
| `message.chainId` | body | integer | Yes | Chain ID of registering chain (within those that are supported by the Network) Example: `421613` |
| `message.timestamp` | body | integer | Yes | timestamp in UNIX milliseconds Example: `1704879369551` |
| `message.registrationNonce` | body | integer | Yes | Registration nonce returned by the delegate signer registration flow. Example: `161111791392` |
| `message.txHash` | body | string | Yes | Transaction hash of the delegate signer authorization transaction. Example: `0xtxhash` |
| `signature` | body | string | Yes | Signature generated by signing the message object. Example: `0x8668447f28534dc1b76566e41f5fcdeb6b131355b9cf428f3fae5c134e9a0fc55642a2771860484651e61043e8ac67a1a6e54031a4c66de44acd77c9d9b281e81b` |
| `userAddress` | body | string | Yes | Address of the wallet that signed the message object. Example: `0xDd3287043493E0a08d2B348397554096728B459c` |

## Responses

### HTTP 200

OK

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | boolean | Yes | Indicates whether the request was successful. Example: `True` |
| `timestamp` | integer | No | Server timestamp in milliseconds. Example: `1702989203989` |
| `data` | object | No | — |
| `data.user_id` | integer | No | Example: `100338` |
| `data.account_id` | string | No | Example: `0xd890c9b8b86fba7312b919e32bbabd619228b32d59f6d0f68fdf4451a684a654` |
| `data.valid_signer` | string | No | Example: `0xc6c4c5c41efa74ebc63c675dcf7034e8382f3a42` |
