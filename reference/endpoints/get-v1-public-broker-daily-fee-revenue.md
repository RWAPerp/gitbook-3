# Get builder daily revenue settlement history (public)

`GET /v1/public/broker/daily_fee_revenue`

**Authentication:** None

**Rate limit:** See platform limits

## Description

Returns daily revenue settlement records for the builder specified by `broker_id`. This public endpoint requires no API key or signature and supports Mainnet and Testnet.

`broker_id`, `start_date`, and `end_date` are required. Dates must use `YYYY-MM-DD`, with `start_date` less than or equal to `end_date`. The date range must be valid and cannot exceed 180 days.

Uses the same revenue fields as [the builder admin daily revenue API](https://rwaperp.xyz/docs/build-on-omnichain/restful-api/private/get-builders-daily-revenue-settlement-history). Each row's `date` is the settlement date, at `00:00 UTC` on the day after the revenue date. Results are sorted by `date` descending.

## Parameters

| Name | Location | Type | Required | Description |
|---|---|---|---|---|
| `broker_id` | query | string | Yes | Builder's broker ID for the requested daily revenue settlement records. |
| `start_date` | query | string | Yes | Start settlement date in UTC, formatted as YYYY-MM-DD. Must be less than or equal to end_date. |
| `end_date` | query | string | Yes | End settlement date in UTC, formatted as YYYY-MM-DD. The range from start_date must not exceed 180 days. |

## Responses

### HTTP 200

Daily revenue settlement records for the requested builder. The example uses illustrative values.

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | boolean | Yes | Indicates whether the request was successful. Example: `True` |
| `timestamp` | integer | No | Server timestamp in milliseconds. Example: `1702989203989` |
| `data` | object | Yes | — |
| `data.rows` | array<object> | Yes | Daily revenue records sorted by date descending. |
| `data.rows[].date` | string | Yes | Settlement date, formatted as `YYYY-MM-DD`. Settlement occurs at `00:00 UTC` on the day after the revenue date. Example: `2026-08-18` |
| `data.rows[].permissionless_listing_fee_share` | number | Yes | Permissionless Listing / PML fee-share revenue generated by Perp Anything markets. The legacy field name is retained for API compatibility. Example: `0` |
| `data.rows[].distributor_fee_share` | number | Yes | Builder's share from distributor relationships. Example: `0` |
| `data.rows[].builder_fee_revenue` | number | Yes | Net fee revenue from the builder's trading platform, calculated as trading fees minus the builder's base fee, after affiliate commission distribution. Example: `0` |
| `data.rows[].cross_broker_fee` | number | Yes | Revenue share generated via cross-builder or tagged order flows (`order_tag`). Example: `0` |
| `data.rows[].total_revenue` | number | Yes | Sum of `permissionless_listing_fee_share`, `distributor_fee_share`, `builder_fee_revenue`, and `cross_broker_fee`. Example: `0` |
